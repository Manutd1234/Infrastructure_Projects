# NUSSIF Infrastructure Projects

Week 1 infrastructure projects for the NUSSIF (National University of Singapore Students' Investment Fund) workflow.

This repository contains three independent projects, each in its own folder:

| Folder | Task | Owner |
|---|---|---|
| [`task1_crypto_bull_cycle/`](task1_crypto_bull_cycle) | 1. Crypto Bull Cycle — BTC cycle analysis, +3σ breakout drift study, drawdowns, SPY benchmark, backtesting | Ting Xuan |
| [`task3_13f_filings/`](task3_13f_filings) | 3. 13F Filings — Dataroma scraper, sector rotation across quarters for 8 hedge funds | Siva |
| [`task4_congress_trading/`](task4_congress_trading) | 4. Congress Trading — house.gov feasibility, Capitol Trades scraper, sector rotation, consensus, committee signals | Veon |

Each folder is self-contained with its own `README.md`, `requirements.txt`, and `main.py`. Run any of them from inside their folder:

```bash
pip install -r requirements.txt
python main.py
```

See each folder's README for methodology and results.
