# Abstract

NUSSIF Infrastructure Projects is a research-and-operations platform that
unifies three quantitative data pipelines — a crypto bull-cycle study, a
13F filings sector-rotation tracker, and a congress trading monitor —
behind a single FastAPI backend and a React dashboard. The platform is
designed for a single operator (a Trading Desk Operations Engineer) who
needs to monitor data freshness, inspect signals, and replay analyses
without writing code.

This whitepaper documents the system's architecture, the methodology of
each pipeline, and the headline results from the most recent run. It is
intended for an institutional reader who wants to understand what the
platform does, how it is built, and what it has found.
